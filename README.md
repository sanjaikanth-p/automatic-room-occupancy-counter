# Automatic Room Occupancy Counter Using ICs

### Digital Logic-Based People Counting and Occupancy Monitoring System

A digital electronics project designed to count room entries and exits and maintain the occupancy count using integrated circuits.

---

## 📌 Project Overview

The Automatic Room Occupancy Counter is an academic hardware project developed as part of the Digital Logic Design course.

The system explores the use of digital logic circuits and integrated circuits to maintain a count of people entering and leaving a room.

The project demonstrates how digital electronics can be applied to basic automated monitoring and counting systems without relying on a microcontroller-based implementation.

## 🎯 Objectives

- Design a digital room occupancy counting system.
- Implement counting logic using digital integrated circuits.
- Understand digital counting and logic operations.
- Develop a hardware-based entry and exit monitoring system.
- Apply digital logic concepts to a practical application.

## 🔬 Working Principle

The system is designed to maintain the number of people present inside a room by accounting for entry and exit events.

The general operating sequence involves:

1. Detecting an entry event.
2. Updating the occupancy count.
3. Detecting an exit event.
4. Decreasing the occupancy count.
5. Maintaining the updated count through digital logic.

## 🔧 Hardware Implementation

The project was implemented using digital integrated circuits.

The hardware development involved assembling the required circuit components, testing the counting functionality and improving the prototype through practical testing.
